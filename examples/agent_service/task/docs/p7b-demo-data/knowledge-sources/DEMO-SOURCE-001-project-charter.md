## 预期咨询范围

1. 收集并核对项目资料和能源计量边界。
2. 对设备编码、位置、投运年份和责任部门字段做完整性分析。
3. 形成节能机会、实施顺序、风险和待核实事项的草稿建议。
4. 对每项项目事实保留可追溯证据；无真实来源时标记为用户输入或待核实。
