# DEMO/SYNTHETIC — 咨询策划报告编制模板

- 演示包来源标记：`DEMO-SOURCE-002`
- 模板类型：项目策划报告编制模板（演示模板）
- 适用项目：`DEMO-LXSCOPE-2025-001`（虚构）
- 资料日期：2025-03-02（虚构）
- 数据状态：合成演示模板；不是发布的企业制度、监管要求或正式标准。

## 八章报告大纲与章节结构

第一章 项目概况：说明委托背景、范围、目标和边界。
第二章 资料清单与可信度：逐份列资料名称、日期、来源和缺口。
第三章 能源基线与计量口径：写明统计范围、时间范围、单位和待核实事项。
第四章 设备台账现状：说明字段、完整性、重复项和需现场核对的数据。
第五章 分析方法与工作计划：说明访谈、数据核验、现场踏勘及输出物。
第六章 方案建议：区分事实、测算、假设和建议，不承诺未经验证的收益。
第七章 预算与进度边界：列演示预算上限和候选周期，并注明未审批。
第八章 风险、待核实事项与交付清单：列责任方、所需证据和复核节点。

## B-01 至 B-15 策划报告编写要求（演示约定）

- B-01 明确项目名称、编号和委托对象。
- B-02 说明咨询范围和不包含事项。
- B-03 说明能源数据的时间范围和计量单位。
- B-04 说明表计边界、缺失数据和校准需求。
- B-05 说明设备台账字段及其来源。
- B-06 区分已收集资料、用户陈述和待取得资料。
- B-07 说明访谈对象类别和记录方式，不虚构访谈结果。
- B-08 说明现场核查步骤和安全前提。
- B-09 说明分析假设、公式和限制。
- B-10 区分节能目标建议值与实际节能量。
- B-11 列出建议措施及其所需验证条件。
- B-12 对预算数字说明来源和审批状态。
- B-13 对工期说明关键依赖和不确定性。
- B-14 列出风险、责任方和需补充证据。
- B-15 列出交付物、复核人和草稿状态。

## 使用限制

本文件可用于检查演示检索是否命中章节结构和条目原文；它不能支持项目面积、实际预算、设备数量或已实现节能效果等现实项目事实。上述章节和 B 条目仅为演示模板内容，不是法定或企业正式要求。
