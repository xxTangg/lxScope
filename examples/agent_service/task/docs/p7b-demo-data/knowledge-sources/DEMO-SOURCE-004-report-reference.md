## 可用于演示报告结构的参考提示

- 报告概况应包含项目目标、范围、资料来源和假设边界。
- 现状分析可以按用能系统、计量口径、设备资产字段和运行数据质量分节。
- 工作计划宜区分资料核验、访谈、现场踏勘、分析和复核步骤。
- 建议应与其来源证据建立对应关系；没有来源的数字须保留待核实标记。
- 对预算、周期和节能目标，应清晰区分委托输入、计算结果、建议值和审批状态。

本演示假设咨询团队先复核电量范围和设备编码，再提出可行性建议。该情境没有提供真实测量值、真实供应商报价、真实节能率或真实验收结果，不能引用为这些事实的证明。
