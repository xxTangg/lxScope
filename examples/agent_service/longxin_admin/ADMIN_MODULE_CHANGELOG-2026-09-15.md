## 一、整体结论

管理员端属于在主目录 `main` 版本基础上的新增模块，代码已尽量从核心业务中解耦，主要管理员业务位于：

```text
examples/agent_service/longxin_admin/
```

主目录原有版本保留，管理员端通过独立的适配层接入用户、套餐、额度、模型凭证和升级备份功能。

## 三、代码解耦位置

本次管理员业务相关代码主要分布如下：

| 目录或文件 | 用途 |
| --- | --- |
| `examples/agent_service/longxin_admin/` | 管理员业务、套餐、充值、升级备份等适配层 |
| `examples/agent_service/longxin_admin/plan_billing/` | 套餐、订单、额度和 Token 使用同步 |
| `examples/agent_service/longxin_admin/credential_policy.py` | 管理员凭证共享策略 |
| `examples/agent_service/admin_api.py` | 管理员成员管理接口 |
| `examples/agent_service/auth.py` | 管理员身份和角色判断 |
| `examples/agent_service/main.py` | 将管理员适配层挂载到应用 |
| `examples/web_ui/frontend/src/pages/admin/` | 管理员页面 |
| `examples/web_ui/frontend/src/pages/account/` | 用户套餐和余额展示 |

核心 AgentScope 的资源访问、凭证和聊天路由只增加了可选的应用级策略钩子；未配置该策略的其他部署仍保持原有行为。

## 五、未完成事项与待确认问题

以下项目不作为本次代码完成项，需后续确认或继续开发：

- [ ] 当前运行环境没有正式配置管理员模型凭证。管理员需要先在管理员端配置供应商凭证，否则普通用户的模型列表为空。
- [ ] 当前“管理员可用模型”按管理员维护的凭证进行共享，暂未建立独立的模型白名单管理表。
- [ ] 各模型独立单价、套餐折扣和不同 Token 类型的扣费规则仍需销售系统确认。
- [ ] 当前 Token 使用量按输入 Token 与输出 Token 计算；是否包含缓存 Token 待确认。
- [ ] 额度同步发生在用户打开套餐页、管理员查看成员列表或用户发起聊天检查时，尚未接入独立的实时扣费事件账本。
- [ ] 同一时间已经开始执行的请求可能在额度检查之后完成；下一次请求会按同步后的余额进行拦截。
- [ ] 在线支付及销售总台接口不在本次负责范围内，销售总台本身未修改。
- [ ] 当前套餐目录中的价格和额度仍需以正式业务配置为准。
- [ ] 全量自动化测试环境尚未安装 `pytest`，当前主要完成了 Python 编译检查、前端 Docker 构建和接口冒烟验证。

## 七、使用说明

1. 管理员登录管理员端。
2. 进入模型配置或凭证配置页面，添加正式供应商凭证。
3. 在成员管理中创建成员并选择套餐。
4. 根据需要为成员补充额外 Token 或处理套餐订单。
5. 普通用户登录后，在账户页面查看自己的套餐和余额。
6. 普通用户在聊天页面只能选择管理员已经配置的模型。

当前开发环境地址：

```text
前端：http://localhost:18200
后端：http://localhost:18201
```
