# 2026-09-22 知识图谱最新 Bug 修复日志

## 修复范围

本次将知识库知识图谱从 AgentScope 知识库主索引链路中迁出，改为
`examples/agent_service` 的应用层按需功能。文档上传、解析和向量索引
不再自动调用图谱抽取。

## 已修复问题

### 1. 点击“启用知识图谱”没有反应

- 原因：前端 API 客户端缺少 `PUT` 方法，启用按钮调用时在浏览器内抛出
  异常；错误仅写入弹窗内部状态，页面上没有可见反馈。
- 修复：补充 `client.put`，读取并更新图谱启用状态；启用成功后自动打开
  预览弹窗，并在弹窗外展示请求错误。

### 2. 预览按钮被置灰，无法查看状态

- 原因：未启用状态直接禁用了预览入口，用户无法进入弹窗获得明确提示。
- 修复：预览入口始终可用；启用状态由轻量设置接口读取。

### 3. 图谱生成导致页面长时间阻塞

- 原因：生成 API 同步等待 LLM 对全部文档分片做实体关系抽取。实际日志中
  单次请求耗时约 100–112 秒。
- 修复：生成请求改为后台任务，接口立即返回 `building`，前端轮询状态；
  失败信息保存到图谱状态并回显。

### 4. 已有节点/关系但首屏画布近似空白

- 原因：首屏先按存储顺序截取节点，再筛选边，常得到彼此无关系的节点；
  同时旧弹窗宽度很小，双栏布局挤压了 NVL 画布。
- 修复：后端优先选择带关系的连通子图；前端首屏限制为 60 节点/120 边，
  并采用 d3-force 布局、适配缩放范围。

### 5. 图谱弹窗与节点交互体验不足

- 修复：弹窗调整为最高 96vw、90vh，支持浏览器右下角调整大小；右侧实体
  详情栏缩窄为 180px。NVL 已启用节点拖动、画布平移、滚轮缩放与悬停交互。

## 接口与存储边界

- 图谱路由由应用层 `knowledge_graph.py` 提供：读取、设置、异步生成。
- Redis 使用独立 `lxscope:kb_graph:*` 前缀，不迁移或复用历史
  `agentscope:knowledge_graph:*` 数据。
- AgentScope 核心应用入口、生命周期和原生知识库图谱路由不再装配该功能。
