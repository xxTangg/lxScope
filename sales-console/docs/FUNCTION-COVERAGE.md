## 客户系统接口

客户系统通过新销售运营中心定义的 `/api/v1/integration/*` 接口接入，并统一要求客户 Bearer Token。该接口边界属于新系统自身，不依赖历史销售总台。

## 已识别的生产化差距

- [ ] 升级任务目前是同步 HTTP 编排，尚未持久化为可重试任务。
- [x] Docker 部署已接入 PostgreSQL；当前通过兼容存储层保存业务数据，正式生产版仍需补充事务、唯一约束和独立表结构。
- [ ] 目前默认只有 `admin` 角色，运营、只读审计等细粒度角色待阶段三实现。
- [x] canonical Token 轮换已提供；旧 Token 立即失效，多 Token 过渡期仍待阶段三实现。

这些是生产化增强项，不影响当前页面和客户系统协议的第一阶段联调。
